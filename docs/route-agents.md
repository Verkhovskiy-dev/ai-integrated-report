# Агенты производства маршрутов

Карта и маршруты обновляются разными контурами. AIwatcher отвечает за карту мест; отдельная линия Route Agents строит и публикует пути освоения позиций.

## Роли

1. **Route Orchestrator** после обновления `places_data.json` сравнивает 53 места с реестром и формирует приоритетную очередь.
2. **Route Builder** получает ровно одно место и создаёт шестишаговый маршрут по JSON-контракту.
3. **Route QA** отклоняет маршрут, если позиция не соответствует месту, отсутствует адресат, первое действие непроверяемо или Eken-бриф не создаёт артефакт.
4. **Route Publisher** активирует прошедший QA маршрут только через PR и после проверки опубликованного bundle.

Конфигурация: `automation/route-agents/pipeline.json`.

## Теневой контур в n8n

В n8n Cloud развёрнут и активирован workflow `Route Agents — Shadow` (`O3EDwzS8BDu1zBG0`). Он запускается по понедельникам в 06:00 по часовому поясу экземпляра и обрабатывает три приоритетных места без маршрутов.

Контур намеренно не имеет узлов записи в GitHub или публикации сайта. Финальный узел всегда возвращает `publishAllowed: false`, а удачный результат переводит только в состояние `manual-review`. Экспорт workflow хранится в `automation/n8n/route-agents-shadow.workflow.json`.

## Подключение к n8n

AIwatcher должен завершаться событием `places-map-updated`. От него запускается отдельный workflow `Route Orchestrator`. Он выполняет планировщик и передаёт каждый элемент `jobs[]` в sub-workflow `Route Builder`; параллелизм ограничен четырьмя заданиями. Результаты сначала сохраняются как drafts. Публикация не должна происходить прямо из LLM-узла.

## Локальная проверка очереди

```bash
node scripts/route-agents/plan-route-jobs.mjs \
  /path/to/places_data.json \
  client/src/data/ekenRoutes.json \
  12
```

## Защита от текущей ошибки

Экран позиции больше не подменяет неизвестный маршрут аудитом. Проверка `validate-published-routes` дополнительно убеждается, что каждый активный `placeId` и `positionRouteId` действительно присутствует в опубликованном JavaScript bundle.
