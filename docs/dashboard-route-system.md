# Модуль Dashboard → Eken

Модуль превращает обновляемый дашборд в систему продуктивных входов. Он не создаёт общий курс по каждому заголовку: для каждой карточки собирается короткий контракт действия — следующий прирост, артефакт, адресат, критерий принятия и время до результата.

## Как работает контур

1. **Entry Analyzer** читает свежий `latest-report.json`, находит новости, тренды, структурные сдвиги, инсайты и фокус дня.
2. Для каждой точки рассчитывается стабильный `sourceId` и fingerprint содержания.
3. **Scenario Builder** пересобирает только новые и изменившиеся сценарии.
4. **Route QA** закрывает публикацию при дубликатах, пустом артефакте, отсутствии адресата или времени вне диапазона 15–480 минут.
5. **Route Compiler** атомарно обновляет `client/src/data/ekenScenarios.json`. Сценарии с `managedBy: manual` сохраняются.
6. `EkenRouteAction` на карточке строит payload и открывает `app.ekenlab.com/integrations/verkhovskiy`.

## Запуск

Только анализ:

```bash
npm run plan:dashboard-routes
```

Анализ, QA и обновление реестра:

```bash
npm run publish:dashboard-routes
```

После обновления отчёта модуль безопасно запускать повторно: неизменившиеся сценарии получают состояние `current`, изменившиеся — `stale`, новые — `new`.

## Поддерживаемые точки входа

- фокус дня — decision brief за 30 минут;
- новость — action brief и действие на 24 часа за 30 минут;
- тренд — карта воздействия и решение о пилоте за 45 минут;
- структурный сдвиг — карта манёвра ОТ → К за 60 минут;
- стратегический инсайт — решение и критерий эффекта за 30 минут.

Карта мест и карта LLM продолжают использовать собственные специализированные адаптеры. Они подключаются к этому же конвейеру событиями `places-map-updated` и `llm-map-updated`; единым остаётся контракт Eken и QA-гейт.
